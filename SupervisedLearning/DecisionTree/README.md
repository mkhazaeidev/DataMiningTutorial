# چالش: پیش‌بینی وضعیت مالی مشتریان بانک

## شرح کسب‌وکار
شما به عنوان یک دانشمند داده در یک بانک بین‌المللی مشغول به کار شده‌اید. مدیریت بانک می‌خواهد یک کمپین بازاریابی هدفمند برای معرفی یک "صندوق سرمایه‌گذاری جدید" به مشتریان خود راه‌اندازی کند. از آنجایی که تماس با تمامی مشتریان پرهزینه و غیرعملی است، آنها نیاز به مدلی دارند که بتواند با دقت بالا مشتریانی را که "احتمالاً از نظر مالی توانایی و تمایل سرمایه‌گذاری دارند" شناسایی کند.

## هدف مدلسازی
شما باید یک مدل درخت تصمیم (Decision Tree) بسازید که بر اساس ویژگی‌های جمعیت‌شناختی و اقتصادی مشتریان، پیش‌بینی کند که آیا یک مشتری سرمایه‌گذاری خواهد کرد یا خیر (این متغیر، برچسب یا Target Variable شماست).

## دیتاست: "Bank Marketing Data Set"
این دیتاست یکی از معروف‌ترین و پاک‌شده‌ترین دیتاست‌ها در حوزه یادگیری نظارت شده است و برای طبقه‌بندی دودویی (Binary Classification) عالی است.

### لینک‌های دانلود
- **صفحه اصلی دیتاست (توضیحات کامل)**: [Bank Marketing Data Set](https://archive.ics.uci.edu/ml/datasets/Bank+Marketing)
- **لینک مستقیم فایل داده (CSV)**: [bank-additional-full.csv](https://archive.ics.uci.edu/ml/machine-learning-databases/00222/bank-additional.zip)

### دستورالعمل استفاده
پس از دانلود، فایل ZIP را اکسترکت کنید. از بین فایل‌ها، `bank-additional-full.csv` را انتخاب کنید چرا که کامل‌ترین نسخه است.

### مشخصات دیتاست
- **تعداد رکوردها**: 41,188
- **تعداد ویژگی‌ها (ستون‌ها)**: 20 ویژگی ورودی + 1 ویژگی هدف (برچسب)
- **مشکل**: طبقه‌بندی دودویی
- **کیفیت داده**: بسیار بالا، Missing Values بسیار ناچیز دارد و از قبل پاک‌سازی شده است.

## راهنمای گام‌به‌گام حل چالش با درخت تصمیم

### گام ۱: بارگذاری و اکتشاف داده (Data Loading & Exploration)
- کتابخانه‌های لازم مانند pandas, numpy, matplotlib, seaborn و scikit-learn را import کنید.
- دیتاست را با `pd.read_csv()` بارگذاری کنید.
- با توابعی مانند `.head()`, `.info()`, `.describe()` و `.value_counts()` داده را بررسی کنید.
- به توازن کلاس (Class Balance) متغیر هدف y (که معمولاً ستون 'y' است و مقادیر 'yes' و 'no' دارد) توجه کنید. آیا داده نامتوازن است؟

### گام ۲: پیش‌پردازش داده (Data Preprocessing)
- **رمزگشایی متغیرها**: متغیر هدف y را به مقادیر عددی (مثلاً 1 برای 'yes' و 0 برای 'no') تبدیل کنید.
- **بررسی مقادیر گمشده**: با `.isnull().sum()` بررسی کنید. اگر مقدار کمی داشت، می‌توانید حذف یا جایگزین کنید.
- **مدیریت متغیرهای دسته‌ای**: دیتاست دارای چندین متغیر رشته‌ای (مانند job, marital, education و ...) است. از OneHotEncoder یا LabelEncoder در Scikit-learn برای تبدیل آن‌ها به عدد استفاده کنید.
- **جداسازی داده به آموزش و آزمون**: از train_test_split استفاده کنید (مثلاً 80% برای آموزش، 20% برای آزمون).

### گام ۳: آموزش مدل پایه (Baseline Model)
- مدل درخت تصمیم را از `sklearn.tree` import کنید (`DecisionTreeClassifier`).
- یک مدل اولیه بدون تنظیم هیپرپارامترها (`max_depth` و ...) آموزش دهید.
- مدل را روی داده آموزش (Train) fit کنید.

### گام ۴: ارزیابی مدل پایه
- پیش‌بینی را روی داده آموزش و داده آزمون انجام دهید.
- معیارهای ارزیابی را محاسبه کنید:
  - دقت (Accuracy)
  - ماتریس درهم ریختگی (Confusion Matrix)
  - گزارش طبقه‌بندی (Classification Report) شامل Precision, Recall, F1-Score
- **تجزیه و تحلیل**: آیا مدل روی داده آموزش Overfit شده است؟ (یعنی دقت آموزش ~100% ولی دقت آزمون پایین است).

### گام ۵: هرس درخت (Pruning) و تنظیم هیپرپارامترها
برای مبارزه با Overfitting، هیپرپارامترهای درخت را تنظیم کنید. مهم‌ترین آن‌ها:
- `max_depth`: حداکثر عمق درخت
- `min_samples_split`: حداقل نمونه مورد نیاز برای تقسیم یک گره
- `min_samples_leaf`: حداقل نمونه مورد نیاز برای یک گره برگ
- `max_leaf_nodes`: حداکثر تعداد گره‌های برگ

می‌توانید از `GridSearchCV` یا `RandomizedSearchCV` برای یافتن بهترین ترکیب این پارامترها استفاده کنید.

### گام ۶: ارزیابی نهایی مدل نهایی
- مدل تنظیم‌شده (Pruned) را روی داده آزمون ارزیابی کنید.
- بهبود معیارها (به ویژه Recall برای کلاس 'yes') را بررسی کنید. چرا Recall مهم است؟ چون می‌خواهیم تا حد امکان تمام مشتریان بالقوه را شناسایی کنیم (False Negative کمتری داشته باشیم)، حتی اگر هزینه آن تماس با تعدادی مشتری غیرعلاقه‌مند (False Positive) باشد.
- درخت تصمیم نهایی را می‌توانید با استفاده از `plot_tree` بصری‌سازی کنید تا قوانین تصمیم‌گیری را ببینید.

## سوالات پیشرفته‌تر برای فکر کردن (اختیاری)
1. اگر دقت مدل روی کلاس اقلیت ('yes') پایین بود، چگونه با استفاده از تکنیک‌هایی مانند SMOTE یا Class Weight می‌توانید آن را بهبود ببخشید؟
2. کدام سه ویژگی (Feature) دارای بیشترین اهمیت در مدل شما هستند؟ (از `feature_importances_` استفاده کنید).
3. نتایج مدل درخت تصمیم خود را با یک مدل ساده‌تر مانند رگرسیون لجستیک مقایسه کنید.
